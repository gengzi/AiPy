## 神经网络

## 张量
张量是一个 n 维数组：
0 维张量：标量（scalar），例如 tensor(5)  
1 维张量：向量（vector），例如 tensor([1, 2, 3])  （数字有多少个就是向量的维度）
2 维张量：矩阵（matrix），例如 tensor([[1, 2], [3, 4]])   二维的数组
3 维及以上：高维数组，常用于图像（如 batch × channel × height × width）
PyTorch 张量是一种支持 GPU 加速、自动微分的多维数组，是构建和训练神经网络的基础数据结构。
每个值都有一个数据类型，如 float32、float64、int32、int64 等。
“几维”看的是：你需要几个「括号」或者几个「索引」才能拿到一个具体的数字。

### 线性变换 + 非线性激活
神经网络的本质是一堆“线性变换 + 非线性激活”。而线性变换的核心就是矩阵乘法
线性变换： y = wx + b
x 是输入张量，w 是权重矩阵，b 是偏置向量，y 是输出张量。

全连接层 （线性层）
非线性激活函数：
1.没有激活函数，会导致线性变换所有层叠加 = 1层的线性变换    是一条直线
激活函数用于破坏线性变化，将其变为非线性变化，让其学习更加复杂的信息
```angular2html
如果把神经网络比作乐高积木：

线性层（权重） = 积木块本身
非线性激活 = 积木块上的凸点和凹槽
没有凹凸（全是光滑方块），你就只能堆成一根柱子（线性）；

有了凹凸（非线性），你才能拼出城堡、飞船、恐龙……（复杂结构）！
```

隐藏层 = 一次 y = Wx + b（线性） + 一次 a = activation(y)（非线性）
```angular2html
输入 x
  │
  ▼
[W1, b1] → 线性变换 → z1    z1 = W1@x + b1
  │
  ▼
ReLU()   → 激活函数 → a1  ← 这就是【隐藏层1的输出，再做为隐藏层2的输入】  
  │
  ▼
[W2, b2] → 线性变换 → z2   z2 = W2@a1 + b2
  │
  ▼
ReLU()   → 激活函数 → a2  ← 这就是【隐藏层2的输出】
  │
  ▼
[W3, b3] → 线性变换 → z3   z3 = W3@a2 + b3
  │
  ▼
softmax  → 概率输出 → y   ← 【输出层】
```

线性变换的过程中会出现升维和降维：
* 降维（压缩）→ 提取精华，去噪
场景：输入维度太高（如图像、文本）
作用：
去掉无关信息（比如背景噪声）
保留对任务有用的特征（比如边缘、笔画）
减少计算量和过拟合风险
* 升维（扩展）→ （扩展）→ 丰富表达能力
场景：输入很简单，但任务很复杂
例子：
输入是10维的用户ID → 映射到128维的“用户兴趣向量”
在Transformer中，把词嵌入从512维扩展到2048维再压缩回来（前馈网络）

```angular2html
这就像一个智能流水线：

原料进来（高维原始数据）
第一站：切掉废料，留下主干（降维）
第二站：添加调料，激发风味（升维/非线性）
最后：包装成客户需要的规格（输出维度）
```

## 常见的非线性激活函数（都长什么样？）

| 名称        | 公式 / 行为             | 图形特点               | 用途               |
| ----------- | ----------------------- | ---------------------- | ------------------ |
| **ReLU**    | `max(0, x)`             | 负半轴平躺，正半轴斜线 | 默认首选，简单高效 |
| **Sigmoid** | `1 / (1 + e⁻ˣ)`         | S形曲线，输出0~1       | 二分类输出层       |
| **Tanh**    | `(eˣ - e⁻ˣ)/(eˣ + e⁻ˣ)` | S形，输出-1~1          | RNN常用            |
| **Softmax** | 归一化指数              | 多分类概率和为1        | 多分类输出层       |



### 损失函数

在训练阶段，评估训练值与真实值的差异（loss） 会给出一个 损失值，在前向传播之前，在反向传播之后

想象你在学做一道菜（比如宫保鸡丁）：

- **你的目标**：做出和师傅一模一样的味道 ✅
- **你第一次尝试**：太咸了、鸡肉老了、花生不够脆 ❌
- **师傅尝了一口**，说：“咸度扣20分，嫩度扣15分，脆度扣10分……总分30/100”

👉 这个“打分标准”就是 **损失函数**！
 👉 “30分”这个具体分数就是 **损失值（loss）**！


常见损失函数举例：

- 分类任务：**交叉熵损失（CrossEntropyLoss）**
- 回归任务：**均方误差（MSELoss）**

梯度由反向传播自动计算，学习率控制更新步长，所有权重据此同步调整。

若发生梯度消失，浅层学不到特征；若爆炸，训练直接崩溃。

改用 ReLU 等激活函数是核心对策，但通常需结合初始化、归一化、网络结构（如 ResNet）等共同解决。
